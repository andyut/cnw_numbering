Document Numbering

Odoo 18 Addons Series

This addon provides a flexible and automated numbering system for documents such as invoices, purchase orders, and sales orders. It supports prefix, suffix, and sequence configuration per company or document type.

Key Features / Fitur Utama

  • Custom prefix & suffix per document type
  • Automatic sequence generation
  • Multi-company support
  • Easy configuration via Settings menu
  • Compatible with Sales, Purchase, and Accounting modules

Preview

How to Use

  1. Add function from Any Model
    2. docnumbering= self.env["cnw.numbering.wizard"].getnumbering('INV',self.docdate)

Example: INV26040001
