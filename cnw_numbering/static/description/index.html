AU-Doc Numbering

Automatic document numbering by company, month, and year

This module helps generate sequential document numbers using a suffix, document date, and company-based sequence control.

Main Features

  • Separate numbering for each company
  • Sequence based on suffix, year, and month
  • Automatic increment for each new document
  • Simple wizard to generate document numbers quickly
  • Easy monitoring from the document numbering menu

How to Use

  1. Open the Document Numbering wizard
  2. Enter the document suffix
  3. Select the document date
  4. Click the button to generate the next number

Example: INV26040001
